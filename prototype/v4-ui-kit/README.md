# V4 Original UI Kit Prototype

这是在低保真 Wireframe 之后的**原创视觉基线**，覆盖全部 46 页。

打开 `index.html` 可逐页切换。

## 与竞品研究的边界

- 页面信息架构来自公开竞品研究。
- 色板、按钮、卡片、街区、头像占位、视觉语言为原创开发基线。
- 不复制《肥鹅美食街》的肥鹅造型、角色立绘、建筑、美术切图、文案或像素级UI。

## 用途

- UI高保真方向评审
- Cocos Prefab实现参考
- 46页状态覆盖检查
- 美术资产拆分
- 后续替换正式原创角色/食物/建筑资源
