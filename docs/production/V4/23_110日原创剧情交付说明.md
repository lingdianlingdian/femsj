# V4 110日原创剧情交付说明

更新时间：2026-09-25

## 交付规模

- 经营日：110
- Story Slice：11
- Story Scene：268
- 原创 zh-CN 对白：821 条
- Day Entry / Exit：220 个
- Build Scene：48 个
- Build Node：48 / 48 有 Story Trigger
- Character Speaker：全部使用 `character_canon_v4.json` 稳定 ID
- Evidence Kind：全部 `DEV_BLUEPRINT`

## 主入口

`production-data/v4/story/story_catalog_v4.json`

Catalog 为 Cocos、剧情播放器、本地化导入、QA 和后续语言扩展提供统一索引。

## 结构

每 10 天一个 Story Slice：

- `story_dialogue_day001_010.json`
- …
- `story_dialogue_day101_110.json`

每个 Slice 有对应：

- `locale_zh-CN_dayXXX_YYY.json`

剧情节奏总表：

`story_beats_110.csv`

## 自动门禁

```powershell
npm run validate:story:all
```

自动发现所有 `story_dialogue_dayXXX_YYY.json`，检查：

1. 同区间 locale 文件存在；
2. 110日 Story Beat Entry / Exit 引用闭合；
3. 48个 BuildNode Story Trigger 闭合；
4. SpeakerId 必须存在于 Character Canon；
5. 所有 TextKey 必须存在于 Locale；
6. TextKey 不重复、不为空；
7. Build Scene Day 必须等于 BuildNode unlockDay；
8. Day1-10 Runtime storyBefore / storyAfter 与 Beat Registry 一致。

## 原创边界

这 110 日剧情是本项目独立原创内容：

- 不复制《肥鹅美食街》人物；
- 不复制竞品剧情；
- 不复制竞品对白；
- 不把竞品公开故事信息改写后冒充原创；
- 玩法研究层与剧情创作层完全分离。

## 长线结构

### Day1-20
第一街区：从基础营业、旧街记录到第一片街区完成。

### Day21-50
第二街区：共享经营、社区协作、运营标准化与交接。

### Day51-80
第三街区：开放空间、峰值能力、天气/活动/物流与弹性运营。

### Day81-110
第四街区：四区整合、统一运营、长期维护、治理交接与正常营业。
