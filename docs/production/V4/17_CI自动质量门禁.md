# V4 CI 自动质量门禁

Workflow：`.github/workflows/v4-quality.yml`

每次 push / pull request 到 main 自动执行：

## Data / Evidence / Content

1. CSV结构审计
2. 持久证据引用审计
3. Item/Order/Transform/Producer引用闭合
4. 关键JSON语法解析
5. Verified Level Slice不变量：
   - unresolved = 0
   - order count一致
   - orderId唯一
   - day count一致

## Contract Smoke

检查以下关键Production Bible入口必须存在且非空：

- AGENTS.md
- OpenAPI
- V4 Schema
- Remote Config Schema
- QA Test Cases
- STATUS
- 低保真46页Wireframe
- 原创高保真46页UI Kit

## 当前已接入的 Runtime / Cocos 门禁

当前全量 Runtime 已形成，CI 已执行：

```powershell
npm run validate:config -- production-data/v4/runtime/game_content_day001_110.json
npm run runtime:check:full
npm run gate:balance:full
npm run gate:balance:full-reachability
npm run cocos:contracts:check
```

其中 `audit:runtime` 当前仍采用报告模式；`audit:runtime:strict` 只应在研究精度缺口满足发版标准后升级为阻断门禁。
