# Day1-10 Vertical Economy Gate

更新时间：2026-09-25

## 目的

验证 Day1-10 原创可运行垂直切片的金币 Source / Sink 与建设成本是否形成可执行闭环。

该门禁只验证 **DEV_BLUEPRINT 经济配置**，不代表《肥鹅美食街》原作金币奖励或建设价格。

## 输入

Runtime：

`production-data/v4/runtime/game_content_day001_010.json`

门禁：

`production-data/v4/runtime/vertical_slice_economy_targets.json`

执行：

```powershell
npm run gate:economy:vertical
```

## 当前假设

- Start Coin = 0
- 同一天内：先结算该日 Order Coin Reward，再支付该日 Build Coin Cost
- 只计算明确配置的 COIN
- Energy / Gem / Item 等不折算为金币
- Build Reward 当前为 Energy，不计 Coin Source
- 不计算广告、IAP、活动、商店出售等额外金币来源

因此该模型偏保守。

## 当前基线

| 指标 | 当前值 | 门禁 |

## 门禁规则

CI 阻断条件：

1. 任一建设节点在假设结算顺序下不可支付；
2. 累计金币低于 0；
3. Day10 结束金币低于 300；
4. Day10 结束金币高于 900；
5. Source / Sink 低于 1.5 或高于 2.2；
6. 任一单日 Build / Source 比超过 1.3。

## 设计解释

当前目标不是让玩家“刚好花光”，而是：

- 前 10 天不因建设成本产生硬卡死；
- 保留可感知积累；
- 建设仍然构成主要金币 Sink；
- 不需要依赖广告/IAP 才能完成基础建设；
- 后续活动与商店加入时仍有调节空间。
