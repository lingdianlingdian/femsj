# V4 Evidence-backed Level Slice

文件：`production-data/v4/levels/verified_level_slice_v4.json`

当前可用于开发联调的**公开证据关卡切片**：

- 17 个经营日
- 113 个逐项转录订单
- 订单需求 ItemId：**113/113 全部映射完成**
- requirement unresolved：**0**

覆盖：
- Day 1–10
- Day 80
- Day 84
- Day 101–105

## 可以拿它做什么

- Board / Order UI 联调
- Item 图标与订单卡绑定
- Day 切换
- 配置加载
- 存档/恢复
- 关卡浏览器
- 内容引用校验

## 还不能用它做什么

不能把当前文件直接当成原作完整数值关卡，因为这些字段仍未公开确认：

- customerId
- coin / extra reward
- Producer 精确依赖
- Recipe 精确依赖
- Cookware 精确依赖
- Producer 掉率/容量/冷却
- Cook duration

这些字段保持 `null/[]` 并列在 `unresolvedRuntimeFields` 中，禁止偷偷用猜测填充。

## 生产原则

公开证据和原创可运行配置分离：

```text
verified_level_slice_v4.json   ← 原作公开证据
runtime_level_config_v4.json   ← 原创产品可运行配置（后续）
```

这样开发可以先跑起来，同时不会污染竞品研究事实。
