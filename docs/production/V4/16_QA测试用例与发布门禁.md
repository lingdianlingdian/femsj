## Severity

- **P0**：发布阻断；经济、存档、支付、并发、作弊、活动结算等。
- **P1**：公开发布前必须通过。
- **P2**：体验与表现质量。

## Automation

- AUTO：单元/集成/服务端自动化。
- VISUAL：截图回归。
- PERF：性能基准。
- MANUAL：需要真实SDK/系统交互或主观视觉判断。

## 发布门禁

- P0：100% PASS
- P1：100% PASS 或有明确批准的临时豁免+Issue
- P2：不得存在影响核心体验的集中失败
- 支付/广告/奖励/存档/活动结算相关用例无豁免

## 回归原则

任何以下模块改动必须触发对应回归：

- Board/ItemGraph → BOARD + PRODUCER + ORDER
- Timer → PRODUCER + COOK + LIVEOPS
- Economy → ECON + ADS + PAY + ORDER
- Save → SAVE + ACCOUNT
- Remote Config → LIVEOPS + ECON
- UI通用组件 → UI全量截图
