# V4 街区 / 建筑布局生产规格

> 本文件是原创同类项目的可执行场景蓝图，不是《肥鹅美食街》原作坐标复刻。

## 已完成

- 4 个主要街区
- 48 个 BuildNode
- 每节点 world x/y
- Footprint
- Click HitArea
- Y-sort key
- 前景遮挡标记
- 每建筑 2 个 NPC Socket
- 建设特效 Socket
- Attention Socket
- 节日换皮 Socket
- 每区域 Camera Bounds / 初始视点

机器数据：
`production-data/v4/build/street_layout_4areas.json`

## Cocos 场景结构

```text
StreetArea
├─ FarBackground
├─ MidGround
│  ├─ BuildNode_01
│  ├─ BuildNode_02
│  └─ ...
├─ NPCPool
├─ ForegroundOccluders
├─ WorldFX
├─ HotspotLayer
└─ CameraRig
```

## 建筑 Prefab

每个正式建筑：

```text
BuildingPrefab
├─ ArtRoot
│  ├─ base
│  ├─ roof
│  ├─ sign
│  ├─ props
│  └─ lights
├─ HitArea
├─ NPCSockets
├─ FXSockets
├─ SeasonalSocket
└─ StateController
```

状态最少：
- BEFORE
- CONSTRUCTING
- AFTER
- AFTER_ALIVE

核心地标可增加 CLEAN / BASIC / DECORATED。

## 对齐门禁

Before / After：
- 同一 Pivot
- 同一 HitArea
- 同一世界基准点
- Bounding box 偏差 ≤ 8%
- 升级动画中不得出现建筑瞬移

## 相机

- 基准逻辑屏幕 750×1334。
- 横向世界大于一屏，允许拖动。
- 不允许拖出 World Bounds 暴露空背景。
- 触摸移动 <10px 视为点击热点，≥10px 转为相机拖动。
- 建设完成可做 0.8–1.2s Camera Focus，但用户触摸立即可打断。

## NPC

- 重要剧情 NPC 使用固定 Socket。
- 普通路人使用区域 Spawn Zone，不和建设热点重叠。
- 高规格 Spine 同屏建议 ≤8。
- 被建筑前景遮挡时按 Y-sort / Occluder Mask 处理。
