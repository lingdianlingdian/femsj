# V4 音频与动效生产规格

## 音频

机器表：
- `production-data/v4/audio/audio_manifest_v4.csv`
- `production-data/v4/audio/audio_manifest_v4.json`

当前 **42 条**音频生产项，覆盖：
- BGM
- Ambient
- UI
- Board
- Producer
- Cooking
- Order
- Economy
- Build
- Album
- Event
- 简短角色拟声

### 混音
- Music / SFX / Ambient / Voice 分 Bus。
- 对白/拟声触发时 Music 自动 Duck -5dB。
- 同屏 Cook Loop 最多3路。
- 高频 Coin/merge SFX 做 80–120ms 节流/聚合，避免“机关枪”声音。
- 所有长循环必须无爆点无接缝。

## 动效

机器表：`production-data/v4/art/motion_manifest_v4.csv`

当前 **21 条**核心动效。

### 统一原则
- 操作反馈 80–220ms。
- 核心合成 300–450ms。
- 奖励/解锁 600–1000ms。
- 建设完成 ≤2.5s。
- 卡包可跳过。
- Reduce Motion 模式关闭大位移、屏幕震动、连续粒子。
- 资源数值在飞行动画抵达后再做最终视觉更新。
