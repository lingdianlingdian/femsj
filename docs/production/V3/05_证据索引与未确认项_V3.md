## 4. 当前不能冒充“原作精确值”的项目

以下仍需后续公网逐帧/真机验证：
1. 所有 Producer 每等级完整掉落池与概率；
2. Producer 容量与冷却精确秒数；
3. 全部 Recipe 加工时间；
4. 11-110 每一天的原作逐单文字化数据；
5. 每天建设金币成本；
6. 当前不同渠道的体力上限/恢复/广告次数；
7. 卡包精确概率；
8. 原作所有活动的完整里程碑表。
