# 《肥鹅美食街》公开资料深度研究包 V2

研究日期：2026-09-24

这是 V1 后的“数据化研究版”，目标不是写一篇竞品介绍，而是把公开网络证据整理成可继续喂给策划、数据分析工具和 Codex 的研究资产。

## 文件

- `01_开发档案_V2.md`：核心研究结论与开发反推。
- `archive/data/research_catalog.json`：证据、事实、数据、缺口的总目录。
- `archive/data/day_menu_01_10.json`：已文字化验证的第1-10天菜单。
- `archive/data/known_transform_graph.json`：目前确认的合成/烹饪转换图。
- `archive/data/liveops_and_economy.json`：活动、商业化与版本化经济参数观察值。
- `archive/data/producer_observations.json`：已公开点名的生产器及证据。
- `archive/data/research_gaps.json`：剩余缺口。
- `archive/schemas/merge_cooking_config.schema.json`：V2时期配置骨架。

## 证据等级

- A：官方/平台直接信息
- B：高可信行业实机拆解
- C：玩家实机、攻略、论坛证据
- D：基于证据的开发推导

> V2仅用于历史追溯；新工作以 V4 为准。
