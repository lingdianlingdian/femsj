# femsj

《肥鹅美食街》竞品研究与同类原创产品开发主仓库。

## 项目目标

把公开研究推进到可直接供策划、UI、美术、Cocos/TypeScript、后端、QA 与 Codex/AI 工程代理使用的 Production Bible。

## 证据规则

- `E-*`：来自公开资料的证据层。
- `D-BLUEPRINT`：为了开发完整性补齐的设计推导。
- 不把推导内容冒充原作后台配置，不复制受版权保护的原作美术、角色、文案或剧情资产。
